### 📚 Research & projects

- 📄 **HAPS: Rethinking Image Similarity for Virtual Staining** — co-author &nbsp;[![arXiv](https://img.shields.io/badge/arXiv-2605.20362-b31b1b?style=flat&logo=arxiv&logoColor=white)](https://arxiv.org/abs/2605.20362)
